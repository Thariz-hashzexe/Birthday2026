Drop your real photos here (e.g. photo1.jpg, photo2.jpg...).

Then open script.js, find the CONFIG.photos array near the top,
and set each entry's "src" to the matching path, e.g.:

  { src: "assets/images/photo1.jpg", caption: "That one summer road trip" }

Until you do, the gallery shows elegant glass placeholder cards
using each photo's caption text, so the site works perfectly
without any images.
